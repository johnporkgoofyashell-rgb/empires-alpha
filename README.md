# EMPIRES Alpha 3.4 — Territory Claims & Era Architecture

- Click **Claim Territory** in the Construction menu to open an in-game modal for the selected tile.
- Use **Claim land: select a tile** to enter claim mode, then click any tile to view eligibility and cost.
- Only discovered, adjacent, unclaimed land can be acquired for 18 wood + 8 stone.
- Houses and civic buildings have distinctive geometry for Primitive, Classical, Medieval, Colonial and Modern eras.
- New buildings keep their construction-era style after research advances. Existing saved buildings receive the current era if their age was not recorded.
- Preserves existing save key, world, economy, military, surveyors, and settlement.

Double-click PLAY EMPIRES.command. If macOS blocks it, right-click → Open or run `chmod +x` on the file.
